# Acme Dashboard

Acme Dashboard is a course project for tracking invoices, customers, and monthly revenue. Signed-in users can search and manage invoices and customer records and see paid and pending totals on the overview.

## Run locally

The application lives in [nextjs-dashboard](nextjs-dashboard/README.md). It uses Next.js App Router, React, TypeScript, Tailwind CSS, PostgreSQL, Auth.js, and Zod. The app README covers installation, database configuration, and sign-in.

## Production

Open the [dashboard on Vercel](https://david-test-ivory.vercel.app/).
